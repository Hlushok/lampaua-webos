# LampaUa webOS package

This repository hosts release metadata for webOS Homebrew distribution.

## Apps
- `com.kinohub.tv` - KinoHub HTTPS package for newer TVs
- `com.lampaua.tv` - LampaUa package
- `com.siaivo.tv` - Siaivo package

## Files
- `com.kinohub.tv.manifest.json` - KinoHub HTTPS manifest
- `com.lampaua.tv.manifest.json` - LampaUa manifest
- `com.siaivo.tv.manifest.json` - Siaivo manifest
- `repo/apps.json` - external repository index for Homebrew Channel
